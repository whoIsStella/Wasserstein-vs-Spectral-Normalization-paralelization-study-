# Wasserstein vs. Spectral Normalization Parallelization Study

Status: reconstruction in progress.

This repository is for a research project comparing Wasserstein-style GAN training and spectral normalization under parallel training workloads.

The original experiments ran on NERSC. I no longer have access to that environment, and the experiment code was not preserved in this repository, so this is currently a reconstruction placeholder rather than a reproducible result.

## Rebuild plan

1. reconstruct the training code from surviving related GAN work
2. use a reproducible public dataset and local or cloud-compatible configuration
3. define the comparison metrics before rerunning experiments
4. measure training stability, throughput, scaling behavior, and model quality
5. publish scripts, environment details, and results here

Related GAN code survives in other research repositories, but it has not yet been verified as the exact code used for the original NERSC experiments.
